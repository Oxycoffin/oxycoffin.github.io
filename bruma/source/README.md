# Bruma original artwork

Six newly generated Adobe Firefly plates, created specifically for this adventure, not reused from previous cat artwork. Cat and cast sheets were isolated with Adobe background removal.

Normal maps are approximate multiscale height derivatives, with silhouette-distance volume for characters; they are not geometrically reconstructed 3D surfaces. The runtime renderer actually decodes and lights these normals.

Seis imágenes originales nuevas para esta aventura. Mapas de normales aproximados a partir de relieves y volumen de silueta, iluminados de verdad por el motor.
