# License evidence / Evidencia de licencias

Store one Markdown or PDF evidence record per stable track ID. It must identify the source file, author/rightsholder, license or commission agreement, acquisition date, permitted uses, and a content hash.

Guarda un registro Markdown o PDF por ID estable de pista. Debe identificar el archivo fuente, autor o titular, licencia o encargo, fecha de adquisición, usos permitidos y hash del contenido.

CC0 evidence should include a durable copy of the declaration; proprietary tracks should include the signed commission/assignment record. Do not place audio files or private personal data in this public repository.
